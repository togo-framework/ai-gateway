# ai-gateway — docs

An AI gateway (control plane) for togo: rate limits, spend caps, response
caching, prompt management, and provider routing/fallback over the AI kit.

- **Install:** `togo install togo-framework/ai-gateway`
- **Marketplace:** https://to-go.dev/plugins/ai-gateway
- **Source:** https://github.com/togo-framework/ai-gateway

See [usage.md](usage.md) for keys, completion, caching, prompts, and the provider adapter.
